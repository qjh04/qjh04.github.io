Go语言基础

2025-11-18 · 3 min · 877 words

因为有一段go语言实习经历，当时实习的时候并没有对go语言进行基础学习，只是将自己对业务的理解，讲给AI让AI写，当提示词工程师。但现在回过头来想看看当时这个项目竟有一些看不下去，虽然后端的业务逻辑上都是相通的，但有一些语法不太相通比如类的方法、接口书写这些与JAVA都不太同，Go语言也是太简洁了。基于对现在的情况分析以及未来的择业准备，我打算在学一遍Go基础，但不会从头开始学有几种变量、控制结构等基础性知识，学这一次的目标是能看懂go程序，能自己上手写简单的crud。

*本文主要用于自己复习，所以语言偏白话

一、基础

1、变量的声明和定义

var a int 声明

a = 10 定义

如果没有定义会有一个默认值0

2、常量的定义

const a int = 10

3、方法的多返回值

func process(a, b int) (int, error) {}

num, err := process(1, 2)

4、数组与动态树组slice

固定数组：nums4 := [5]int{1, 2, 3, 4, 5}

动态数组：nums := make([]int, 0, 5) nums = append(nums, 10)

5、map

cache := make(map[int]string)

cache[1] = “one”

cache[2] = “two”

6、面向对象

封装：

类属性：

type Person struct {

​ Name string// 前边字段名后边属性

​ Age int // age大写代表别的包可以访问

}

类方法：

func (p *Person) PrintHello() {

​ fmt.Println(“hello world!”)

}

方法名大写代表别的包可以调用，前边的括号代表该方法是哪个对象的方法，如果没有就是一个普通的接口

继承：

type Student struct {

​ Person // 代表继承父类person

​ Class string

}

如果有需要也可以重写父类方法

多态：

需要先介绍一下接口：

type Person interface {

​ GetName() string // 首字母大写代表其他包可以访问

​ GetName(name strirng)

}

需要实现该接口的类，重写上面接口的所有方法即可完成实现，例如

type Student struct {

​ Name string

}

func (s * Student) GetName () string {

​ return s.Name

}

func (s *Student) SetName(nastring) {

​ s.Name = na

}

如果有多个类，所有类都需要实现这几个接口，这里假设实现了Teacher类，实现多态如下：

person := &Student{“zhangsan”}

person.GetName();

person := &Teacher{“lisi”}

person.GetName();

父引用指向不同的子类调用相同的方法根据各自子类的实现展现出不同的特点即为多态。

7、反射

根据reflect包中的api可以获取变量的类型和值，如果是复杂类型，根据类型可以获取该类型的字段、方法等元信息。

如字段后面的tag标签， 可以用于gorm持久化、json序列化字段名、前端联调等信息。

8 、goroutine

协程，运行在用户态的轻量级线程，更高的切换效率更低的资源消耗，为高并发而生。多个线程对应若干个process，每个process又对应多个协程，这就是GMP模型。其他在详细的内容可以找个网站、博客、书籍看

9 、channel

协程间的通信方式，可以用

m := make(chan int)

m就是一个无缓存式channel，可以用m <- num对其进行发送数据，num <-m将channel中的数据给到nun，可以给一个capacity变为有缓存式类似生产者消费者模型。
