📚 核心准备清单（按优先级排序）

一、 Java 基础（重中之重，必问）

  1. 面向对象特性

    • 封装、继承、多态的具体体现和理解。
    • final, static 关键字的作用。

  2. 集合框架

    • HashMap：底层结构（数组+链表/红黑树）、扩容机制、put/get流程、线程不安全问题、ConcurrentHashMap如何保证线程安全（JDK7 vs JDK8）。
    • ArrayList vs LinkedList：底层实现、增删改查的复杂度对比。
    • HashSet：如何保证元素不重复。

  3. 异常体系

    • Exception 和 Error 的区别。
    • 检查型异常 vs 非检查型异常。
    • try-catch-finally 的执行顺序，finally 什么情况下不会执行。

  4. 并发编程（高频难点）

    • 线程状态 及转换。
    • synchronized 关键字：作用、锁升级过程（无锁 -> 偏向锁 -> 轻量级锁 -> 重量级锁）。
    • volatile 关键字：保证可见性、禁止指令重排。
    • JUC包：
      • ReentrantLock 原理，与 synchronized 的区别。
      • ConcurrentHashMap 的并发原理。
      • ThreadLocal 原理、使用场景及内存泄漏问题。
    • 线程池：ThreadPoolExecutor 的七大核心参数、工作流程、常见的拒绝策略。

  5. JVM 内存模型

    • 运行时数据区（程序计数器、虚拟机栈、本地方法栈、堆、方法区）。
    • 垃圾回收算法（标记-清除、标记-复制、标记-整理）。
    • 常见的垃圾回收器（CMS, G1）。
    • 类加载过程（加载、连接、初始化）。

  6. 新特性

    • Java 8：Lambda表达式、Stream API、Optional、新的日期时间API。

二、 数据库（MySQL + Redis）

  1. MySQL

    • 索引：B+树结构、聚簇索引 vs 非聚簇索引、最左前缀原则、索引失效场景。
    • 事务：ACID特性、事务隔离级别（读未提交、读已提交、可重复读、串行化）及各自解决的问题（脏读、不可重复读、幻读）。
    • 锁：全局锁、表级锁、行级锁、间隙锁、Next-Key Lock。
    • 优化：EXPLAIN 命令各字段含义（type, key, rows, Extra）、慢查询排查。

  2. Redis

    • 数据类型及应用场景：String, Hash, List, Set, Zset。
    • 持久化机制：RDB 和 AOF 的优缺点。
    • 过期策略与内存淘汰机制。
    • 缓存穿透、缓存击穿、缓存雪崩 的原因及解决方案。
    • Redis 为什么快？（基于内存、单线程、IO多路复用）。

三、 计算机基础（CS Basics）

  1. 计算机网络

    • TCP vs UDP：区别、TCP的三次握手与四次挥手。
    • HTTP：
      • HTTP 1.0/1.1/2.0 的区别。
      • 常见状态码（200, 301, 302, 400, 403, 404, 500, 502）。
      • GET 与 POST 的区别。
    • HTTPS：工作原理（如何通过SSL/TLS保证安全）。

  2. 操作系统

    • 进程 vs 线程 的区别。
    • 进程/线程间通信方式。
    • 用户态与内核态。

四、 开发框架（Spring + SpringBoot）

  1. Spring

    • IoC 控制反转：概念、原理、好处。
    • AOP 面向切面编程：概念、应用场景（日志、事务等）、实现原理（动态代理）。
    • Bean 的生命周期和作用域。
    • 事务管理：声明式事务的传播行为。

  2. SpringBoot

    • 自动配置原理：@SpringBootApplication, @EnableAutoConfiguration。
    • starter 机制。

  3. MyBatis

    • #{} 和 ${} 的区别（防SQL注入）。
    • 一级缓存和二级缓存。

五、 中间件与分布式

  1. 消息队列

    • 作用：解耦、异步、削峰填谷。
    • 如何保证消息不丢失？（生产者确认、Broker持久化、消费者手动ACK）。
    • 如何保证消息顺序性？（同一业务键发到同一分区/队列）。

  2. 分布式基础概念

    • CAP理论、BASE理论。
    • 分布式ID生成方案（雪花算法）。

💡 面试准备策略

  1. 理解而非背诵：面试官更看重你是否真正理解了原理，而不是死记硬背。多思考“为什么这么设计”。
  2. 知识串联：尝试将知识点串联起来。例如，问到 HashMap 时可以延伸到 ConcurrentHashMap，再延伸到 synchronized 和锁。
  3. 项目结合：准备1-2个你在学校做过的项目（课程设计、个人项目均可），思考项目中用到了哪些技术，为什么这么选，遇到了什么问题，如何解决的。
  4. 手写代码：刷一些 LeetCode 上的简单/中等题目，重点是数组、字符串、链表、二叉树。面试中可能会让你手写。
  5. 准备提问：最后面试官会让你提问，准备一些有深度的问题，如：“团队的技术栈是什么？”“新人会有怎样的培养机制？”

最后，保持自信和积极的学习态度。作为应届生，面试官不会要求你具备所有实战经验，但会非常看重你的基础扎实度、学习潜力和解决问题的思路。

祝你面试顺利！
